# Meta Hub UX Rewrite — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild MedArbeiter One from two pages into a four-page Meta hub — Today, Inbox, Campaigns, Customers — with customer as a global URL-driven scope filter.

**Architecture:** Server components read URL search params directly and call a thin Graph layer (`lib/graph.ts` → `lib/customers.ts` / `lib/campaigns.ts` / `lib/inbox.ts`); network lives at the edges, pure transforms in the middle, and only the pure transforms get tests. Mutations are server actions returning `{ ok?, error? }`. The brand is applied by overriding HeroUI 3's CSS custom properties, so every HeroUI component retints without per-component classes.

**Tech Stack:** Next.js 16.3.0 (App Router, no `cacheComponents`), React 19.2.8, HeroUI 3.2.4, Tailwind CSS 4, bun 1.3.14, Meta Graph API v26.0.

**Spec:** `docs/superpowers/specs/2026-08-11-meta-hub-ux-design.md`

## Global Constraints

- **No new dependencies.** Everything is covered by `@heroui/react@3.2.4`, `next@16.3.0`, `react@19.2.8`. If a task seems to need a package, it is the wrong task.
- **UI language is English.** Every user-visible string. Code comments stay German to match the existing files.
- **`cacheComponents` is NOT enabled.** So `'use cache'`, `cacheLife()` and `cacheTag()` are unavailable. Caching is `fetch(url, { next: { revalidate, tags } })`; invalidation is `updateTag(tag)` inside server actions (`revalidateTag` without a profile is deprecated in Next 16).
- **Every filter is a URL search param.** No client filter state, no `useEffect`. Scope is `?customer=<id>`.
- **`Promise.allSettled` for every fan-out.** One customer failing must never blank a page.
- **Campaigns are always created `PAUSED`.** Going live is a separate confirmed action.
- **Gold (`#DAA21D`) means brand and primary action only** — never "warning". Urgency is red-tinted. Text on gold fills is ink `#1A1A1A`, never white.
- **Tests:** `bun test` only, no framework, no fixtures. Pure functions only. Never test that `fetch` was called.
- **Before writing Next-specific code**, read the relevant file under `node_modules/next/dist/docs/` (per `AGENTS.md`). The `AGENTS.md` agent-rules block is regenerated by `next dev`; commit it with your work rather than reverting it.
- **Commit style:** conventional commits (`feat:`, `fix:`, `refactor:`, `chore:`), one per task, ending with the `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>` trailer.
- **HeroUI 3.2.4 API corrections** (found during execution — the JSX in later tasks was written against the wrong prop names). Before writing any HeroUI JSX, check the sub-part names and props in `node_modules/@heroui/react/dist/components/<name>/index.d.ts`. Confirmed so far:
  - `Alert` takes `status="danger"`, **not** `color=`. `Chip` does take `color=`.
  - `Button` has no `as` prop — for a link, use a plain `next/link` `<Link>` with `buttonVariants()` from `@heroui/styles`.
  - The imperative toast API is the lowercase `toast` export (`toast.success(msg)` / `toast.danger(msg)`). There is no `Toast.add`. Capitalised `Toast` is the component namespace; mount `Toast.Provider` in the layout.
  - `AlertDialog` has **no** `.Content` sub-part. The real nesting is `AlertDialog > Backdrop > Container > Dialog > Header > Heading`, then `Body`, then `Footer`.
  - `ComboBox.Value` is read-only — use `Input` inside `ComboBox.InputGroup` for a typable combo box, and give every `ListBox.Item` a `textValue`, or type-to-filter silently breaks.
  - `Popover.Content` needs an inner `Popover.Dialog` for correct aria and Escape handling.
- **Branch:** `design/meta-hub-ux` (already checked out). The working tree carries unrelated uncommitted changes — stage only the files a task names.

## Deviation from spec §8

Spec §8 puts the scope switcher and token-health indicator in stage 1. Both need the customer list, which does not exist until stage 3. They move to Tasks 8 and 9, after `lib/customers.ts`. The rest of the stage ordering is unchanged.

Spec §2 asks the Inbox context pane to name the ad ("ad 3"). Graph gives no post→ad edge on the comment itself, so Task 19 builds that mapping from `{ad-account}/ads?fields=creative{effective_object_story_id}`. It is a separate task because everything before it works without it.

```ts
/**
 * Alles gegen die Graph API läuft durch `graph()`. Kein SDK, kein OAuth-Flow:
 * ein System-User-Token aus dem Business Manager reicht (siehe README).
 */

const API = `https://graph.facebook.com/${process.env.META_API_VERSION ?? "v26.0"}`;

// Aus dem Ads Manager kopierte IDs kommen ohne "act_" – Graph braucht es aber.
export const actId = (id: string) =>
  !id || id.startsWith("act_") ? id : `act_${id}`;

export const meta = {
  business: process.env.META_BUSINESS_ID ?? "",
  adAccount: actId(process.env.META_AD_ACCOUNT_ID ?? ""),
};

function token() {
  const t = process.env.META_ACCESS_TOKEN;
  if (!t) throw new Error("META_ACCESS_TOKEN missing – see README.md");
  return t;
}

export type GraphFailure = {
  kind: "token" | "permission" | "rate" | "unknown";
  message: string;
  retryable: boolean;
};

export class GraphError extends Error {
  kind: GraphFailure["kind"];
  retryable: boolean;
  constructor(f: GraphFailure) {
    super(f.message);
    this.name = "GraphError";
    this.kind = f.kind;
    this.retryable = f.retryable;
  }
}

// 190 = Token tot, 4/17/32/613 = Rate-Limit, 10/200/272 = fehlende Berechtigung.
// Die Einordnung entscheidet, was der Mensch zu sehen bekommt – nicht der Text.
export function mapGraphError(err: any, status = 0): GraphFailure {
  const code = err?.code ?? 0;
  const message = err?.error_user_msg || err?.message || `Graph ${status || "request failed"}`;
  if (code === 190) return { kind: "token", message, retryable: false };
  if ([4, 17, 32, 613].includes(code)) return { kind: "rate", message, retryable: true };
  if ([10, 200, 272, 294].includes(code))
    return { kind: "permission", message, retryable: false };
  return { kind: "unknown", message, retryable: status >= 500 };
}

export type GraphOpts = {
  method?: "GET" | "POST" | "DELETE";
  params?: Record<string, unknown>;
  body?: FormData;
  /** Sekunden. Ohne diesen Wert wird nicht gecacht (richtig für Mutationen). */
  revalidate?: number;
  tags?: string[];
};

export async function graph<T = any>(path: string, opts: GraphOpts = {}): Promise<T> {
  const { method = "GET", params = {}, body, revalidate, tags } = opts;
  const url = new URL(`${API}/${path}`);
  url.searchParams.set("access_token", token());
  for (const [k, v] of Object.entries(params)) {
    if (v === undefined || v === null) continue;
    url.searchParams.set(k, typeof v === "object" ? JSON.stringify(v) : String(v));
  }

  const init: RequestInit =
    revalidate === undefined
      ? { method, body, cache: "no-store" }
      : { method, body, next: { revalidate, tags } };

  // ponytail: drei Versuche, fester Backoff. Auf einen Token-Bucket erst
  // umbauen, wenn Rate-Limits im Normalbetrieb auftreten statt in Spitzen.
  for (let attempt = 0; ; attempt++) {
    const res = await fetch(url, init);
    const json = await res.json();
    if (res.ok) return json as T;
    const failure = mapGraphError(json?.error, res.status);
    if (!failure.retryable || attempt >= 2) throw new GraphError(failure);
    await new Promise((r) => setTimeout(r, 1000 * 2 ** attempt));
  }
}
```

```ts
export type BatchRequest = { method?: "GET" | "POST"; relative_url: string };

type BatchItem = { code: number; body: string } | null;

// Sub-Requests scheitern einzeln – deshalb PromiseSettledResult statt Werfen.
export function unwrapBatchItem<T>(item: BatchItem): PromiseSettledResult<T> {
  if (!item)
    return {
      status: "rejected",
      reason: new GraphError({ kind: "unknown", message: "Batch sub-request timed out", retryable: true }),
    };
  let body: any;
  try {
    body = JSON.parse(item.body);
  } catch {
    body = undefined;
  }
  if (item.code >= 200 && item.code < 300) return { status: "fulfilled", value: body as T };
  return { status: "rejected", reason: new GraphError(mapGraphError(body?.error, item.code)) };
}

/**
 * Graph erlaubt 50 Sub-Requests pro POST; alles darüber wird gestückelt.
 * `relative_url` ohne Version – die steckt schon in der Ziel-URL.
 * ponytail: Blöcke laufen nacheinander. Parallel erst, wenn >150 Requests
 * pro Seitenaufruf zusammenkommen; vorher provoziert es nur Rate-Limits.
 */
export async function batch<T = any>(
  reqs: BatchRequest[],
  opts: { revalidate?: number; tags?: string[] } = {},
): Promise<PromiseSettledResult<T>[]> {
  const out: PromiseSettledResult<T>[] = [];
  for (let i = 0; i < reqs.length; i += 50) {
    const chunk = reqs.slice(i, i + 50);
    const items = await graph<BatchItem[]>("", {
      method: "POST",
      params: {
        batch: chunk.map((r) => ({ method: r.method ?? "GET", relative_url: r.relative_url })),
        include_headers: false,
      },
      ...opts,
    });
    out.push(...items.map((item) => unwrapBatchItem<T>(item)));
  }
  return out;
}
```

```ts
/**
 * Der Kunde ist die Einheit, in der die Agentur denkt – Meta kennt ihn nicht.
 * Hier wird er aus Konfiguration (customers.config.ts) und Portfolio gebaut.
 */
import { actId, graph, GraphError, meta } from "./graph";
import { customers as config, type CustomerConfig } from "./customers.config";

export type Access = "own" | "client";

export type AdAccount = {
  id: string;
  name: string;
  account_status: number;
  currency: string;
  access: Access;
};

export type Page = {
  id: string;
  name: string;
  link?: string;
  fan_count?: number;
  access: Access;
};

export type Customer = {
  id: string;
  name: string;
  page?: Page;
  igId?: string;
  adAccounts: AdAccount[];
  access: Access;
  /** Leer heißt: alles zugewiesen. Sonst steht hier, was fehlt. */
  issues: string[];
};

export function joinCustomers(
  config: CustomerConfig[],
  accounts: AdAccount[],
  pages: Page[],
): Customer[] {
  const acc = new Map(accounts.map((a) => [a.id, a]));
  const pg = new Map(pages.map((p) => [p.id, p]));

  return config.map((c) => {
    const page = pg.get(c.pageId);
    const wanted = c.adAccountIds.map(actId);
    const adAccounts = wanted.map((id) => acc.get(id)).filter((a): a is AdAccount => !!a);

    const issues: string[] = [];
    if (!page) issues.push(`Page ${c.pageId} is not in the portfolio`);
    for (const id of wanted)
      if (!acc.has(id)) issues.push(`Ad account ${id} is not in the portfolio`);

    return {
      id: c.id,
      name: c.name,
      page,
      igId: c.igId,
      adAccounts,
      access: page?.access ?? adAccounts[0]?.access ?? "client",
      issues,
    };
  });
}

// Kundenkonten liegen unter client_*, eigene unter owned_* – die Agentur braucht beides.
const EDGES = [
  ["owned_ad_accounts", "accounts", "own"],
  ["client_ad_accounts", "accounts", "client"],
  ["owned_pages", "pages", "own"],
  ["client_pages", "pages", "client"],
] as const;

// ponytail: erste Seite mit 500 Einträgen, kein Paging. Reicht bis ~500 Kunden.
export async function listAssets() {
  const settled = await Promise.allSettled(
    EDGES.map(([edge, kind]) =>
      graph<{ data: any[] }>(`${meta.business}/${edge}`, {
        params: {
          fields: kind === "accounts" ? "name,account_status,currency" : "name,link,fan_count",
          limit: 500,
        },
        revalidate: 300,
        tags: ["assets"],
      }),
    ),
  );

  const accounts: AdAccount[] = [];
  const pages: Page[] = [];
  const errors: GraphError[] = [];

  // Promise.allSettled statt all: ein Kunde ohne Freigabe darf nicht die
  // ganze Seite leeren – genau das war der Fehler in listAssets() vorher.
  settled.forEach((r, i) => {
    const [, kind, access] = EDGES[i];
    if (r.status === "rejected") {
      errors.push(r.reason as GraphError);
      return;
    }
    const tagged = r.value.data.map((d) => ({ ...d, access }));
    if (kind === "accounts") accounts.push(...(tagged as AdAccount[]));
    else pages.push(...(tagged as Page[]));
  });

  return { accounts, pages, errors };
}

export async function listCustomers() {
  const { accounts, pages, errors } = await listAssets();
  return { customers: joinCustomers(config, accounts, pages), errors };
}

export const findCustomer = (all: Customer[], id?: string) =>
  id ? all.find((c) => c.id === id) : undefined;
```

```tsx
"use client";

import { ComboBox, ListBox } from "@heroui/react";
import { usePathname, useRouter, useSearchParams } from "next/navigation";

const ALL = "__all__";

export function ScopeSwitcher({ customers }: { customers: { id: string; name: string }[] }) {
  const router = useRouter();
  const pathname = usePathname();
  const params = useSearchParams();

  // Der Scope steht in der URL, nicht im State – sonst überlebt er keinen
  // Seitenwechsel und keinen Zurück-Button.
  function select(key: React.Key | null) {
    const next = new URLSearchParams(params);
    if (!key || key === ALL) next.delete("customer");
    else next.set("customer", String(key));
    // Bei Wechsel des Kunden ist die alte Auswahl in der Liste bedeutungslos.
    next.delete("item");
    const qs = next.toString();
    router.push(qs ? `${pathname}?${qs}` : pathname);
  }

  const items = [{ id: ALL, name: "All customers" }, ...customers];

  return (
    <ComboBox
      aria-label="Customer scope"
      selectedKey={params.get("customer") ?? ALL}
      onSelectionChange={select}
      className="w-64"
    >
      <ComboBox.InputGroup>
        <ComboBox.Value />
        <ComboBox.Trigger />
      </ComboBox.InputGroup>
      <ComboBox.Popover>
        <ListBox items={items}>
          {(c: { id: string; name: string }) => <ListBox.Item id={c.id}>{c.name}</ListBox.Item>}
        </ListBox>
      </ComboBox.Popover>
    </ComboBox>
  );
}
```

```tsx
"use client";

import Link from "next/link";

export type SearchParams = Record<string, string | string[] | undefined>;

/**
 * Ein GET-Formular ist der ganze Filtermechanismus: der Browser schreibt die
 * Felder in die Query, Server Components lesen sie direkt. Kein Client-State,
 * kein useEffect, und jede gefilterte Ansicht ist ein teilbarer Link.
 */
export function Facets({ customer, children }: { customer?: string; children: React.ReactNode }) {
  return (
    <form
      className="border-line bg-surface flex flex-wrap items-center gap-2 rounded-lg border p-2"
      onChange={(e) => (e.currentTarget as HTMLFormElement).requestSubmit()}
    >
      {customer && <input type="hidden" name="customer" value={customer} />}
      {children}
    </form>
  );
}

// ponytail: natives <select> statt HeroUI-Select – so kommt die Filterzeile
// ohne State aus. Auf ComboBox erst umstellen, wenn eine Facette suchbar sein muss.
const control =
  "border-line bg-surface text-ink-700 h-9 rounded-md border px-2 text-sm";

export function FacetSelect({
  name,
  label,
  options,
  value,
}: {
  name: string;
  label: string;
  options: [string, string][];
  value?: string;
}) {
  return (
    <select name={name} aria-label={label} defaultValue={value ?? ""} className={control}>
      <option value="">{label}</option>
      {options.map(([v, l]) => (
        <option key={v} value={v}>
          {l}
        </option>
      ))}
    </select>
  );
}

export function FacetSearch({ value }: { value?: string }) {
  return (
    <input
      type="search"
      name="q"
      defaultValue={value ?? ""}
      placeholder="Search"
      aria-label="Search"
      className={`${control} min-w-48 flex-1`}
    />
  );
}

/** Pure: welche Facetten sind gesetzt, und wohin führt ihr Entfernen. */
export function activeChips(params: SearchParams, labels: Record<string, string>) {
  const set = Object.entries(labels).filter(([k]) => {
    const v = params[k];
    return typeof v === "string" && v.length > 0;
  });

  return set.map(([key, label]) => {
    const next = new URLSearchParams();
    for (const [k, v] of Object.entries(params))
      if (k !== key && typeof v === "string" && v) next.set(k, v);
    return { key, label: `${label}: ${params[key]}`, href: `?${next.toString()}` };
  });
}

export function ActiveFilters({
  params,
  labels,
}: {
  params: SearchParams;
  labels: Record<string, string>;
}) {
  const chips = activeChips(params, labels);
  if (!chips.length) return null;
  const scope = typeof params.customer === "string" ? `?customer=${params.customer}` : "";

  return (
    <div className="flex flex-wrap items-center gap-2 text-xs">
      {chips.map((c) => (
        <Link
          key={c.key}
          href={c.href}
          className="bg-gold-100 text-ink-900 rounded-full px-2 py-1 hover:line-through"
        >
          {c.label} ✕
        </Link>
      ))}
      <Link href={scope || "?"} className="text-gold-700 underline">
        Reset all
      </Link>
    </div>
  );
}
```

```ts
/**
 * Kampagnen über alle Werbekonten eines Scopes – Konten werden gebündelt
 * abgefragt, damit "Alle Kunden" nicht 18 Einzelaufrufe bedeutet.
 */
import { batch, graph, GraphError } from "./graph";
import type { Customer } from "./customers";

export type Period = "today" | "last_7d" | "last_30d" | "maximum";

export type Insights = {
  spend?: string;
  impressions?: string;
  cpm?: string;
  actions?: { action_type: string; value: string }[];
};

export type Campaign = {
  id: string;
  name: string;
  status: string;
  objective: string;
  daily_budget?: string;
  start_time?: string;
  customerId?: string;
  customerName?: string;
  insights?: Insights;
};

// Rangfolge, nicht Summe: ein Lead ist auch ein Klick, doppelt zählen wäre falsch.
const RESULT_ACTIONS = [
  "onsite_conversion.lead_grouped",
  "lead",
  "offsite_conversion.fb_pixel_lead",
  "landing_page_view",
  "link_click",
  "post_engagement",
];

export function results(insights?: Insights): number | undefined {
  const actions = insights?.actions;
  if (!actions?.length) return undefined;
  for (const type of RESULT_ACTIONS) {
    const hit = actions.find((x) => x.action_type === type);
    if (hit) return Number(hit.value);
  }
  return undefined;
}

export function costPerResult(insights?: Insights): number | undefined {
  const n = results(insights);
  const spend = Number(insights?.spend);
  if (!n || !Number.isFinite(spend) || !insights?.spend) return undefined;
  return spend / n;
}

const FIELDS = (period: Period) =>
  `name,status,objective,daily_budget,start_time,insights.date_preset(${period}){spend,impressions,cpm,actions}`;

export async function listCampaigns(customers: Customer[], period: Period) {
  // Ein Sub-Request pro Werbekonto; die Zuordnung zum Kunden merkt sich der Index.
  const owners = customers.flatMap((c) => c.adAccounts.map((a) => ({ acct: a.id, c })));
  const settled = await batch<{ data: Campaign[] }>(
    owners.map((o) => ({
      relative_url: `${o.acct}/campaigns?fields=${encodeURIComponent(FIELDS(period))}&limit=100`,
    })),
    { revalidate: 60, tags: ["campaigns"] },
  );

  const campaigns: Campaign[] = [];
  const errors: GraphError[] = [];
  settled.forEach((r, i) => {
    if (r.status === "rejected") {
      errors.push(r.reason as GraphError);
      return;
    }
    const { c } = owners[i];
    for (const raw of r.value.data ?? [])
      campaigns.push({
        ...raw,
        insights: (raw as any).insights?.data?.[0],
        customerId: c.id,
        customerName: c.name,
      });
  });

  return { campaigns, errors };
}

export function getCampaign(id: string, period: Period) {
  return graph<Campaign & { adsets?: { data: any[] } }>(id, {
    params: {
      fields: `${FIELDS(period)},adsets{name,status,daily_budget,optimization_goal,billing_event,targeting,insights.date_preset(${period}){spend,impressions,cpm,actions},ads{name,status,creative{thumbnail_url,effective_object_story_id},insights.date_preset(${period}){spend,impressions,cpm,actions}}}`,
    },
    revalidate: 60,
    tags: ["campaigns", `campaign:${id}`],
  });
}

export const setStatus = (id: string, status: "ACTIVE" | "PAUSED") =>
  graph(id, { method: "POST", params: { status } });

export const setDailyBudget = (id: string, cents: number) =>
  graph(id, { method: "POST", params: { daily_budget: cents } });
```

```ts
/**
 * Vier Graph-Formen (FB-Kommentare, IG-Kommentare, Messenger, IG-DMs) werden
 * hier zu einem Typ. Alles danach – Liste, Filter, Sortierung, Badge, Uhr –
 * kennt nur noch InboxItem.
 */

export type Channel = "facebook" | "instagram";

export type InboxItem = {
  id: string;
  kind: "comment" | "dm";
  channel: Channel;
  customerId: string;
  author: { id: string; name: string; avatar?: string };
  text: string;
  createdAt: string;
  context?: { label: string; thumbnail?: string; adId?: string };
  /** Nur DMs: createdAt + 24h. Danach nimmt Meta keine Antwort mehr an. */
  expiresAt?: string;
  /** Abgeleitet: hat die Seite in diesem Thread geantwortet? */
  answered: boolean;
};

export type RawComment = {
  id: string;
  message?: string;
  created_time: string;
  from?: { id: string; name?: string };
  comments?: { data: { from?: { id: string }; created_time: string }[] };
};

export type RawPost = {
  id: string;
  message?: string;
  full_picture?: string;
  comments?: { data: RawComment[] };
};

export type RawConversation = {
  id: string;
  updated_time: string;
  unread_count?: number;
  participants?: { data: { id: string; name?: string }[] };
  messages?: {
    data: { id: string; message?: string; created_time: string; from?: { id: string; name?: string } }[];
  };
};

export type Source = {
  customerId: string;
  channel: Channel;
  /** Seiten- bzw. IG-Konto-ID – "wir" in jedem Thread. */
  selfId: string;
  posts: RawPost[];
  conversations: RawConversation[];
};

const DAY = 24 * 60 * 60 * 1000;

export const expiresAt = (createdAt: string) =>
  new Date(Date.parse(createdAt) + DAY).toISOString();

export const isExpired = (item: Pick<InboxItem, "expiresAt">, now = Date.now()) =>
  item.expiresAt !== undefined && Date.parse(item.expiresAt) <= now;

const label = (s?: string) =>
  !s ? "Post" : s.length > 60 ? `${s.slice(0, 57)}…` : s;

export function normalize(sources: Source[]): InboxItem[] {
  const items: InboxItem[] = [];

  for (const s of sources) {
    for (const post of s.posts) {
      for (const c of post.comments?.data ?? []) {
        items.push({
          id: c.id,
          kind: "comment",
          channel: s.channel,
          customerId: s.customerId,
          author: { id: c.from?.id ?? "", name: c.from?.name ?? "Unknown" },
          text: c.message ?? "",
          createdAt: new Date(c.created_time).toISOString(),
          context: { label: label(post.message), thumbnail: post.full_picture },
          // Kein Graph-Feld für "erledigt" – deshalb abgeleitet aus den Antworten.
          answered: (c.comments?.data ?? []).some((r) => r.from?.id === s.selfId),
        });
      }
    }

    for (const t of s.conversations) {
      const last = t.messages?.data?.[0];
      const other = (t.participants?.data ?? []).find((p) => p.id !== s.selfId);
      const created = new Date(last?.created_time ?? t.updated_time).toISOString();
      items.push({
        id: t.id,
        kind: "dm",
        channel: s.channel,
        customerId: s.customerId,
        author: { id: other?.id ?? "", name: other?.name ?? "Unknown" },
        text: last?.message ?? "",
        createdAt: created,
        expiresAt: expiresAt(created),
        answered: last?.from?.id === s.selfId,
      });
    }
  }

  return items.sort((a, b) => Date.parse(b.createdAt) - Date.parse(a.createdAt));
}
```

```ts
import { batch, GraphError } from "./graph";
import type { Customer } from "./customers";

const COMMENT_FIELDS = "id,message,created_time,from{id,name},comments.limit(25){id,from{id},created_time}";
const POST_FIELDS = `id,message,full_picture,comments.limit(25){${COMMENT_FIELDS}}`;
const CONV_FIELDS = "id,updated_time,unread_count,participants,messages.limit(1){id,message,created_time,from}";

type Slot = { customerId: string; channel: Channel; selfId: string; part: "posts" | "conversations" };

export async function listInbox(customers: Customer[]) {
  const slots: Slot[] = [];
  const reqs: { relative_url: string }[] = [];

  const add = (slot: Slot, url: string) => {
    slots.push(slot);
    reqs.push({ relative_url: url });
  };

  for (const c of customers) {
    if (!c.page) continue;
    const page = c.page.id;
    add({ customerId: c.id, channel: "facebook", selfId: page, part: "posts" },
      `${page}/feed?fields=${encodeURIComponent(POST_FIELDS)}&limit=25`);
    add({ customerId: c.id, channel: "facebook", selfId: page, part: "conversations" },
      `${page}/conversations?fields=${encodeURIComponent(CONV_FIELDS)}&limit=25`);
    add({ customerId: c.id, channel: "instagram", selfId: c.igId ?? page, part: "conversations" },
      `${page}/conversations?platform=instagram&fields=${encodeURIComponent(CONV_FIELDS)}&limit=25`);
    if (c.igId)
      add({ customerId: c.id, channel: "instagram", selfId: c.igId, part: "posts" },
        `${c.igId}/media?fields=${encodeURIComponent(`id,caption,media_url,comments.limit(25){${COMMENT_FIELDS}}`)}&limit=25`);
  }

  const settled = await batch<{ data: any[] }>(reqs, { revalidate: 60, tags: ["inbox"] });

  // Ein Kunde ohne Nachrichten-Freigabe darf den Posteingang nicht leeren.
  const bySource = new Map<string, Source>();
  const errors: GraphError[] = [];

  settled.forEach((r, i) => {
    const s = slots[i];
    if (r.status === "rejected") {
      errors.push(r.reason as GraphError);
      return;
    }
    const key = `${s.customerId}:${s.channel}`;
    const src =
      bySource.get(key) ??
      { customerId: s.customerId, channel: s.channel, selfId: s.selfId, posts: [], conversations: [] };
    if (s.part === "posts")
      // IG nennt Text "caption" und Bild "media_url" – hier auf FB-Form gebracht.
      src.posts.push(
        ...(r.value.data ?? []).map((p: any) => ({
          ...p,
          message: p.message ?? p.caption,
          full_picture: p.full_picture ?? p.media_url,
        })),
      );
    else src.conversations.push(...(r.value.data ?? []));
    bySource.set(key, src);
  });

  return { items: normalize([...bySource.values()]), errors };
}

export function getThread(item: InboxItem) {
  return item.kind === "comment"
    ? graph<{ comments?: { data: any[] } } & any>(item.id, {
        params: { fields: `${COMMENT_FIELDS}` },
        revalidate: 30,
        tags: ["inbox", `thread:${item.id}`],
      }).then((c) => [c, ...(c.comments?.data ?? [])])
    : graph<{ data: any[] }>(`${item.id}/messages`, {
        params: { fields: "id,message,created_time,from", limit: 25 },
        revalidate: 30,
        tags: ["inbox", `thread:${item.id}`],
      }).then((r) => r.data.slice().reverse());
}
```

```ts
/** Kommentare hängen am Beitrag; die Anzeige dahinter steht nur im Creative. */
export async function adPostMap(customers: Customer[]) {
  const accounts = customers.flatMap((c) => c.adAccounts.map((a) => a.id));
  const settled = await batch<{ data: { id: string; name: string; creative?: { effective_object_story_id?: string } }[] }>(
    accounts.map((a) => ({
      relative_url: `${a}/ads?fields=name,creative{effective_object_story_id}&limit=200&effective_status=["ACTIVE","PAUSED"]`,
    })),
    // Anzeigen ändern sich selten – eine Stunde reicht und spart 18 Aufrufe je Seitenaufruf.
    { revalidate: 3600, tags: ["ads"] },
  );

  const map = new Map<string, { adId: string; name: string }>();
  for (const r of settled) {
    if (r.status === "rejected") continue;
    for (const ad of r.value.data ?? []) {
      const post = ad.creative?.effective_object_story_id;
      if (post) map.set(post, { adId: ad.id, name: ad.name });
    }
  }
  return map;
}

export function attachAds(
  items: InboxItem[],
  map: Map<string, { adId: string; name: string }>,
): InboxItem[] {
  return items.map((i) => {
    const hit = i.postId ? map.get(i.postId) : undefined;
    if (!hit || !i.context) return i;
    return { ...i, context: { ...i.context, adId: hit.adId, label: hit.name } };
  });
}
```

```ts
"use server";

import { updateTag } from "next/cache";
import { graph } from "@/lib/graph";
import { isExpired, type InboxItem } from "@/lib/inbox";
import { findCustomer, listCustomers } from "@/lib/customers";
import type { LaunchResult } from "@/app/campaigns/actions";

export async function replyAction(item: InboxItem, text: string): Promise<LaunchResult> {
  if (!text.trim()) return { error: "Write something first." };
  // Serverseitig prüfen, nicht nur im UI – zwischen Rendern und Senden liegt Zeit.
  if (isExpired(item))
    return { error: "The 24-hour reply window for this conversation has closed." };

  try {
    if (item.kind === "comment") {
      await graph(`${item.id}/comments`, { method: "POST", params: { message: text } });
    } else {
      const { customers } = await listCustomers();
      const page = findCustomer(customers, item.customerId)?.page?.id;
      if (!page) return { error: "No page connected for this customer." };
      await graph(`${page}/messages`, {
        method: "POST",
        params: {
          recipient: { id: item.author.id },
          message: { text },
          messaging_type: "RESPONSE",
        },
      });
    }
    updateTag("inbox");
    return { ok: "Reply sent." };
  } catch (e) {
    return { error: (e as Error).message };
  }
}

export async function hideAction(commentId: string, hidden: boolean): Promise<LaunchResult> {
  try {
    await graph(commentId, { method: "POST", params: { is_hidden: hidden } });
    updateTag("inbox");
    return { ok: hidden ? "Comment hidden." : "Comment shown again." };
  } catch (e) {
    return { error: (e as Error).message };
  }
}

export async function deleteAction(commentId: string): Promise<LaunchResult> {
  try {
    await graph(commentId, { method: "DELETE" });
    updateTag("inbox");
    return { ok: "Comment deleted." };
  } catch (e) {
    return { error: (e as Error).message };
  }
}
```

```tsx
          <Alert.Title>Reply window closed</Alert.Title>
          <Alert.Description>
            Meta only accepts replies within 24 hours of the last message. This conversation can no
            longer be answered here.
          </Alert.Description>
        </Alert.Content>
      </Alert>
    );

  return (
    <div className="space-y-2">
      <TextField value={text} onChange={setText} className="space-y-1">
        <TextArea rows={3} placeholder="Write a reply…" />
      </TextField>

      <div className="flex items-center gap-2">
        <Button isDisabled={pending || !text.trim()} onPress={() => run(() => replyAction(item, text))}>
          Reply
        </Button>

        {item.expiresAt && (
          <span className="text-ink-500 text-xs tabular-nums">
            Reply by{" "}
            {new Date(item.expiresAt).toLocaleTimeString("en-GB", { hour: "2-digit", minute: "2-digit" })}
          </span>
        )}

        {item.kind === "comment" && (
          <>
            <Button variant="outline" isDisabled={pending} onPress={() => run(() => hideAction(item.id, true))}>
              Hide
            </Button>
            <Button variant="outline" color="danger" isDisabled={pending} onPress={() => setConfirmDelete(true)}>
              Delete
            </Button>
          </>
        )}
      </div>

      <AlertDialog isOpen={confirmDelete} onOpenChange={setConfirmDelete}>
        <AlertDialog.Content>
          <AlertDialog.Header>
            <AlertDialog.Heading>Delete this comment?</AlertDialog.Heading>
          </AlertDialog.Header>
          <AlertDialog.Body>
            It disappears from the customer’s page for everyone and cannot be restored. Hiding is
            reversible; deleting is not.
          </AlertDialog.Body>
          <AlertDialog.Footer>
            <Button variant="outline" onPress={() => setConfirmDelete(false)}>Cancel</Button>
            <Button color="danger" onPress={() => { setConfirmDelete(false); run(() => deleteAction(item.id)); }}>
              Delete
            </Button>
          </AlertDialog.Footer>
        </AlertDialog.Content>
      </AlertDialog>
    </div>
  );
}
```

```tsx
import Link from "next/link";
import { Card, Chip, EmptyState, Table } from "@heroui/react";
import { findCustomer, listCustomers } from "@/lib/customers";
import { listCampaigns } from "@/lib/campaigns";
import { isExpired, listInbox } from "@/lib/inbox";

const SIX_HOURS = 6 * 3600_000;
const money = (n: number) =>
  new Intl.NumberFormat("en-GB", { style: "currency", currency: "EUR" }).format(n);

export default async function TodayPage({ searchParams }: PageProps<"/">) {
  const sp = await searchParams;
  const customerId = typeof sp.customer === "string" ? sp.customer : undefined;

  const { customers } = await listCustomers();
  const scope = findCustomer(customers, customerId);
  const inScope = scope ? [scope] : customers;

  const [{ items }, { campaigns }] = await Promise.all([
    listInbox(inScope),
    listCampaigns(inScope, "last_7d"),
  ]);

  const open = items.filter((i) => !i.answered);
  // Zuerst das, was unwiderruflich wird, wenn es liegen bleibt.
  const expiring = open
    .filter((i) => i.expiresAt && !isExpired(i) && Date.parse(i.expiresAt) - Date.now() < SIX_HOURS)
    .sort((a, b) => Date.parse(a.expiresAt!) - Date.parse(b.expiresAt!));
  const awaiting = campaigns.filter((c) => c.status === "PAUSED");
  const spend = campaigns.reduce((s, c) => s + (Number(c.insights?.spend) || 0), 0);

  const scoped = (href: string) => (customerId ? `${href}?customer=${customerId}` : href);

  return (
    <div className="space-y-4">
      <h1 className="font-display text-ink-900 text-2xl">
        Today{scope ? ` · ${scope.name}` : ""}
      </h1>

      <Card>
        <Card.Header>
          <Card.Title>Expiring soon</Card.Title>
          <Card.Description>Direct messages inside the last 6 hours of their reply window.</Card.Description>
        </Card.Header>
        <Card.Content>
          {expiring.length ? (
            <ul className="divide-line divide-y text-sm">
              {expiring.map((i) => (
                <li key={i.id}>
                  <Link href={`/inbox?item=${i.id}&customer=${i.customerId}`} className="flex items-center gap-3 py-2">
                    <span className="text-ink-900 font-medium">{i.author.name}</span>
                    <span className="text-ink-500 flex-1 truncate text-xs">{i.text}</span>
                    <span className="text-danger shrink-0 text-xs tabular-nums">
                      {new Date(i.expiresAt!).toLocaleTimeString("en-GB", { hour: "2-digit", minute: "2-digit" })}
                    </span>
                  </Link>
                </li>
              ))}
            </ul>
          ) : (
            <EmptyState className="text-ink-500 py-4 text-sm">Nothing about to expire.</EmptyState>
          )}
        </Card.Content>
      </Card>

      <Card>
        <Card.Header>
          <Card.Title>Awaiting approval</Card.Title>
          <Card.Description>Campaigns created here that are still paused.</Card.Description>
        </Card.Header>
        <Card.Content>
          {awaiting.length ? (
            <ul className="divide-line divide-y text-sm">
              {awaiting.slice(0, 10).map((c) => (
                <li key={c.id}>
                  <Link href={`/campaigns/${c.id}`} className="flex items-center gap-3 py-2">
                    <span className="text-ink-900 flex-1 truncate">{c.name}</span>
                    <span className="text-ink-500 text-xs">{c.customerName}</span>
                    <Chip size="sm">Paused</Chip>
                  </Link>
                </li>
              ))}
            </ul>
          ) : (
            <EmptyState className="text-ink-500 py-4 text-sm">Nothing waiting for approval.</EmptyState>
          )}
        </Card.Content>
      </Card>

      <div className="grid gap-4 sm:grid-cols-4">
        <Stat label="Open comments" value={open.filter((i) => i.kind === "comment").length} href={scoped("/inbox")} />
        <Stat label="Open DMs" value={open.filter((i) => i.kind === "dm").length} href={scoped("/inbox")} />
        <Stat label="Active campaigns" value={campaigns.filter((c) => c.status === "ACTIVE").length} href={scoped("/campaigns")} />
        <Stat label="Spend (7 days)" value={money(spend)} href={scoped("/campaigns")} />
      </div>

      {/* Genau diese Tabelle ist die Aufgabe "alle Facebook-Konten durchsehen". */}
      {!scope && (
        <Card>
          <Card.Header><Card.Title>By customer</Card.Title></Card.Header>
          <Card.Content>
            <Table>
              <Table.Content aria-label="Per customer">
                <Table.Header>
                  <Table.Column isRowHeader>Customer</Table.Column>
                  <Table.Column>Open comments</Table.Column>
                  <Table.Column>Open DMs</Table.Column>
                  <Table.Column>Active campaigns</Table.Column>
                  <Table.Column>Spend (7 days)</Table.Column>
                </Table.Header>
                <Table.Body>
                  {customers
                    .map((c) => {
                      const mine = open.filter((i) => i.customerId === c.id);
                      const cc = campaigns.filter((x) => x.customerId === c.id);
                      return {
                        c,
                        comments: mine.filter((i) => i.kind === "comment").length,
                        dms: mine.filter((i) => i.kind === "dm").length,

  );
}

}
```

## Notes carried forward

Things deliberately not built, and the signal that says build them:

- **A `done` store for comments.** `answered` is derived from "has the page replied", which is right about 90% of the time; comments needing no reply keep reappearing. Add a one-column SQLite file (`done: commentId`) when that becomes annoying — not before.
- **Paging.** Every list takes the first page (500 assets, 100 campaigns, 25 comments/messages per source). Add cursors when a customer's inbox visibly truncates.
- **Parallel batch chunks.** `batch()` runs its 50-request chunks sequentially. Parallelise above ~150 requests per page load; earlier just invites rate limits.
- **Saved filter views.** The URL is the saved view. Add real ones only after repeatedly rebuilding the same filter set by hand.
- **A `⌘K` command palette.** It appears in the spec's shell sketch (§2) but in no page description, and nothing in the workflow needs it once the scope switcher is searchable. Build it when navigating between four pages actually feels slow.
- **The inbox badge double-fetch.** The layout calls `listInbox` for the count and the page calls it again; both hit the same 60-second tagged cache entry. Split it out when the count measurably slows navigation.
